Instructions
SETUP
Follow every step carefully. You must disable security features and use WinRAR or 7-Zip to extract files.
01
Disable Microsoft Vulnerable Driver Blocklist

Search for Windows Security in Settings → go to Device security.

Click Core isolation details and turn Memory integrity and the Vulnerable Driver Blocklist OFF.

Path: Windows Security → Device security → Core isolation details

02
Install WinRAR or 7-Zip

Important: You must use WinRAR or 7-Zip to extract the files. Windows built-in extractor will not work properly with the password-protected archive.

Download WinRAR → Download 7-Zip →

Install one of them before continuing to the next step.

03
Download Defender Control

Go to the official Sordum page and download Defender Control.

Scroll down until you see the white download button.

Open Sordum Download Page →

The archive is password protected. Use the password below with WinRAR or 7-Zip:

Password: sordum
04
Disable Windows Defender completely

Extract the downloaded file with WinRAR or 7-Zip using the password sordum.

Run dControl.exe as Administrator and click the red button to disable Windows Defender.

Also open Windows Security → Virus & threat protection and turn off Real-time protection, Cloud-delivered protection, and Automatic sample submission.

Supported: Windows 11, 10, 8.1, 8, 7, Vista (32/64-bit)

05
Run the Loader

Once Defender and the Vulnerable Driver Blocklist are fully disabled, go back to the Loader page and download the latest build.

Run DumpysLoader.exe as Administrator.

If you still get blocked, restart your PC after disabling the protections and try again.
